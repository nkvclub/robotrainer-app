# Задание для агента сайта: тест v3.1 (без секунд до конца теста)

Проблема: после каждого замера в строке шага видны секунды и длина полоски («45 с», «30 с»). Это подсказка результата до конца теста. По правилу проекта до третьего замера ничего показывать нельзя.

Что меняется: после каждого шага строка показывает полную нейтральную полоску и «готово ✓» (EN: «done ✓»). Все цифры, цвета и итог появляются только после третьего замера, как раньше. Пороги, тексты подсказок и минута отдыха не меняются.

## Файлы
- `ru-v3-1.html` — новый скрипт для robotrainer.ru (заменяет скрипт со строкой `Blind test v3`)
- `en-v3-1.html` — новый скрипт для robotrainerpro.com (то же)
- `ru-v3-seichas.html`, `en-v3-now.html` — то, что стоит сейчас (для отката)

Код сделан из того, что сейчас стоит на сайтах; изменены только 3 места: добавлена функция `doneMark`, и два вызова `neutral(...)` для завершённых шагов заменены на `doneMark(m)`.
В английском файле нет знака амперсанда (WordPress его ломает), там стоит `&amp;`.

## Шаги
1. Сохрани текущий код.
2. Замени скрипт теста на обоих сайтах.
3. Очисти кеш.
4. Проверь: после первого замера в строке «готово ✓» без секунд; после третьего появляются секунды и итог; в коде страницы есть `Blind test v3.1`; в консоли нет ошибок.

# Задание для агента сайта: тест v3.2

Ставим на оба сайта сразу v3.2 (в ней уже есть v3.1). Если v3.1 ещё не поставлена, её ставить не нужно.

Что меняется по сравнению с тем, что стоит сейчас (v3):
1. После каждого замера в строке шага вместо секунд «готово ✓» (EN «done ✓»). Цифры и итог только после третьего замера.
2. Шаг 3: под подсказкой поле «Сколько приседаний сделал?» (EN «How many squats did you do?»). Пока число не вписано, кнопка замер не запускает и просит вписать число. После ввода появляется команда «Отлично! Теперь сядь, вдохни, задержи дыхание и жми на кнопку!». Таймера на приседания нет.
3. Число приседаний на оценку не влияет (пороги и алгоритм прежние), только сохраняется в браузере в localStorage `rtSquats`.

## Шаги
1. Сохрани текущий код.
2. Замени скрипт теста (строка `Blind test v3` или `v3.1`) целиком на новый файл на каждом сайте.
3. Очисти кеш.
4. Проверь: в коде страницы есть `Blind test v3.2`; после шага 1 «готово ✓» без секунд; на шаге 3 есть поле для числа; без числа кнопка не стартует; после ввода появляется команда; итог после третьего замера; в консоли нет ошибок.

## Письмо с разбором (данные из приложения)
Приложение будет присылать на `POST /wp-json/rt/v1/app-lead` новое необязательное поле `squats` — целое число 1–100 (сколько приседаний человек сделал на шаге 3).
Пример тела: `{"key":"…","email":"…","consent":true,"lang":"ru","inhale":51,"exhale":51,"load":31,"squats":18,"website":""}`. Приложение шлёт `squats: 0`, если число не вписано.
1. Принимать `squats` как целое; если поля нет, пустое или вне 1–100 — просто не использовать (старые версии приложения его не шлют, ошибкой это не считать).
2. В письме с разбором показать одну строку только как информацию, без оценки и без сравнения:
   - RU: «Приседаний на шаге 3: N»
   - EN: «Squats in step 3: N»
3. Если числа нет, строку не показывать. Пороги и тексты оценки не менять.
